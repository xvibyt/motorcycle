# motorcycle
Currently a small prototype game about driving a motorcycle with semi-realistic physics.

How?
Everything is scripted in GDScript inside of Godot.

Why?
I wanted to make a vehicle which is fun to drive. In the future I might use it as a base for other games with vehicles.

# Test it:
On itch.io:
https://xvibyt.itch.io/motorcycle

Or if you want to load up the project files yourself:
1. Download the "motorcycle" folder in this repository
2. Click the import button inside Godot and select the project

Controls:
W: Accelerate

S: Reverse

A/D: Turn Left/Right

Shift: Hold while turning to drift

Currently only features a drivable motorcycle and a "zombie" ragdoll.
